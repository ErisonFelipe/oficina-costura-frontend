## ✨ Sobre o projeto

Site institucional **moderno e elegante** desenvolvido para apresentar os serviços da oficina de costura **Lunnexx**.

O design combina **minimalismo, sofisticação e detalhes artesanais** — com linhas costuradas animadas, texturas sutis de tecido e microinterações que remetem à costura.

### 🎯 Principais recursos

- **Design artesanal premium** — terracota, off-white e tipografia serifada
- **Animações elegantes** — Framer Motion + linha de costura no scroll
- **Formulário funcional** — integrado com a API na AWS
- **Galeria dinâmica** — consome imagens reais do backend
- **Responsivo** — experiência fluida em desktop e mobile
- **SEO otimizado** — meta tags, Open Graph, favicon personalizado

## 🚀 Tecnologias

- **React 18** + **Vite** + **TypeScript**
- **Tailwind CSS** — estilização utilitária
- **Framer Motion** — animações
- **React Icons** — iconografia
- **React Router** — navegação
